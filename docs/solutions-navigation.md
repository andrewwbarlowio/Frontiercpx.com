# Solutions navigation

Desktop primary Businesses tab is now Solutions; the existing dropdown and destinations remain. The desktop More menu uses the Solutions heading.

Mobile corporate links start About Us, then a collapsed Solutions button. Tapping or pressing Enter/Space toggles an indented accordion containing the ten existing categories, in the same order and with the same URLs. The former separate Our businesses block is removed from mobile navigation. No page copy, routes, service taxonomy or backend behaviour has changed.

Browser verified: Solutions directly follows About Us; ten links appear on expansion; Enter collapses and removes those links from focus/navigation; menu has no horizontal overflow at 390px. Desktop label and ArrowDown dropdown opening checked. Shared 114-route build passes.
